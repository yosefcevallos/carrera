Carrera app, fintech v1

A terminal-style take on app.carrera.xyz: aligned mono numbers, hairlines instead of blocks, and small signs of a live system. It uses the numbers from your screenshot. Logos are placeholders, so keep your real ones at 24px.

Numbers firstEvery figure is in a mono face, right-aligned and tabular. Tickers are 14px labels, and the APY is the answer.
Live systemA status line with the funding cycle, a countdown, the Solana slot and the last update. Changed values flash briefly.
One summaryBalance, earned, your APY and protocol TVL in a single bracketed bar. Zero-state protocol stats are gone.
Order ticketThe modal works like an exchange ticket: amount, percentage chips, a receipt-style summary, one red button, then a transaction receipt.
01Vaults, desktop 1280, hovering TSLA, sorted by APY
Status line. A live dot, the current funding cycle and a countdown to the next, the Solana slot, and "Updated 2m ago". It tells you the numbers are real and current.
Summary bar. Four cells with corner brackets, echoing the landing page. "Earned" stays grey at 0.00, and positive values turn red.
Table. Asset, APY with a status dot, a 7-day funding line on a shared scale, position (USD over token amount), earned, and a chevron. Headers sort, and search filters by ticker.
02Order ticket: deposit, withdraw, confirmed
Deposit. One mono amount with ≈ USD and balance, 25/50/75/Max chips, then a dashed receipt: receive, exposure, est. yearly, fee, settles.
Withdraw. The same ticket, showing the settlement epoch and countdown, with the exit fee only when it applies.
Confirmed. A transaction receipt with a timeline, a signature link and a Done button, instead of a toast that disappears.
